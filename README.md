# PixelArtIcon

PixelArtIcon is a Minecraft texture project that creates pixel art icons for items and materials. It follows strict pixel art rules, including a 1-pixel colored outline, a 7-tone ramp for the material, and specific lighting and specular effects. The project ensures high-quality, consistent pixel art icons for Minecraft items and materials.

## Install

1. Download the project files from the GitHub repository.
2. Extract the downloaded files to a directory of your choice.
3. Copy the desired icon files from the `assets/textures` directory to your Minecraft resource pack's `assets/minecraft/textures/item` directory.

## Use

1. Create a new resource pack or use an existing one.
2. Place the copied icon files in the appropriate directory within your resource pack.
3. Enable the resource pack in your Minecraft game settings.
4. The custom pixel art icons will now be displayed in your Minecraft inventory and game.
